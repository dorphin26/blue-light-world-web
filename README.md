# blue-light-world-web

푸른빛의 세계 웹게임 버전입니다.

## v0.1 목표

프롤로그의 첫 공간인 루카스의 저택 서재를 기반으로, 웹게임의 핵심 상호작용을 검증합니다.

- WASD 이동
- 가까운 물품 조사 (E)
- 짧은 조사 텍스트
- 획득 정보의 탐험 일지 기록
- 탐험 일지 열기 (J)
- 향후 모바일 터치 조작과 실제 아트 리소스를 추가할 수 있는 구조

## 실행

```bash
npm install
npm run dev
```

브라우저에서 Vite가 표시하는 로컬 주소로 접속하면 됩니다.
